# Blackpaw identity kit v2

Authority: user-approved `Marketing sheet access issue (5).zip` and `(6).zip`.

## Included

- 53 exact approved PNGs, unchanged, under approved-v2/.
- 106 genuine vector SVGs under v2/svg/: 53 counterparts to the approved PNGs and 53 supporting assets.
- 106 PNG renders of those SVGs under v2/png/.
- A multi-size favicon.ico, searchable catalogue, change record and validation report.

The catalogue defaults to approved originals for the 53 supplied designs. Use Compare SVG previews to inspect vector reconstructions. Each download is explicitly labelled. Set 6 is the primary type direction; Set 5 remains the approved legacy collection.

## Approved direction

Midnight #140F33 with violet #7A2FA8 and plum #4B1E55 glows for digital/social. Flat ink navy #0A0A3A for print/documents. Warm white #FBF7F2 on dark. Coral #FF6461 on light and #FF8A7A on dark. The rebuilt signature background has the violet base, coral top-right, indigo bottom-right and ink bottom-left described in set 5.

Set 6: 3h mono wordmark; 3i one-line tagline; 3q horizontal; 3r stacked; 3v gradient wordmark plus tagline. All ten supplied variants are included.

## SVG reconstruction

Original mark and legacy lettering geometry comes from the original BLACKPAW LOGOS.pdf. The new wordmarks use Montserrat ExtraBold for BLACK, Light for PAW, and SemiBold for the tagline, matched against the approved PNGs. The gradient wordmark uses ExtraBold throughout. Text is converted to paths, so no fonts need installing to use the SVGs. Positions and spacing are measured from the approved images.

The approved dark-mark colour adjustment was sampled from the approved transparent mark and reconstructed as an SVG gradient. This replaces the first kit's pastel interpretation. New type gradients are reconstructed against the supplied PNGs.

Background SVGs use editable linear and radial gradient layers fitted to the approved raster references. They are close reconstructions, not the original source design files. All exact approved PNGs remain available. Validation records comparisons and any limitations; the generated vectors and derivatives are not falsely labelled as separately approved originals.

## Practical use

Use the new horizontal/stacked type lockups as primary. Mark-only icons avoid an unreadable tagline. Supplementary no-tagline masters preserve the approved mark and wordmark treatment. White/ink small icons and thermal print files are updated to the new direction.

Maintain one wordmark B height of clear space, consistent with the existing brand guide. SVGs use RGB; obtain a physical proof for colour-critical printing. Receipt PNG is 1-bit at 384 px. Sticker files contain artwork, not a vendor cutting path. Black foreground remains available for engraving/thermal print; pure-black backgrounds are excluded.

Montserrat outlines are embedded as paths. The catalogue uses existing Urbanist font files with their OFL licence. The source artwork and the user-supplied archives are unchanged.
