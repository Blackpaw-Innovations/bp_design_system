# Copilot document prompt

Paste this at the start of every Blackpaw proposal, profile or report. When in doubt, the [Blackpaw Brand Book](./blackpaw-brand-book.html) wins.

```text
Build this as a Blackpaw document using bp_design_system.
Read BRAND.md, docs/brand/BRAND_RESOLUTIONS_2026-10-09.md and src/tokens/ first.
Google Sans for text, JetBrains Mono for figures, IDs, dates and short labels.
Pages white + #EBEAFA panels, accent #3228CF, text #0D0D50.
Purple #451D6A only for a specific product or offering.
Cover: light blue #EBEAFA (default), midnight #140F33 or navy #0D0D50.
Section transitions: one clean abstract image on #09081A.
Gradient only as a thread (rules, hairlines, big numerals): #FE635F > #8441B1 > #3228CF; never behind the logo or as a background.
Logos only from src/assets/brand/blackpaw/logo/; never redraw or retype the name.
Proposition: "We make complex businesses easier to run." CTA: "Book a consultation".
No "seamless", no "studio", no unsourced numbers. Label demo data.
```
