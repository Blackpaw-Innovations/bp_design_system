03 · Expression

One brand. Five modes.

Select a mode according to the communication job, not personal taste. Clear is the default for business documents and ordinary product surfaces.

Review summary

Clear

Light Blue + White, Purple focus. Default documents, explainers, onboarding.

Authority

Purple + Dark with restrained Coral. Governance, executive and high-stakes moments.

Human

Coral + White with Purple anchors. Care, culture, celebration and support.

Precision

Blue + White. Product actions, technical material and operational clarity.

Signature

Controlled multi-colour expression. Launches, covers and rare memorable moments.

08 · Build guide

For people and copilots.

Begin with the brand's intent, then consume its semantic implementation. A generated artefact is not compliant merely because it uses purple.

1. Read

Start with BRAND.md. Coding agents must also follow AGENTS.md.

2. Consume

Import src/tokens/index.css, the Tailwind preset, and components. Select assets by manifest ID.

3. Validate

Run npm run check:brand, then test access, responsiveness, states, language, and the three-step task rule.
