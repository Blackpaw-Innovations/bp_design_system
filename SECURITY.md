# Security Policy

## Scope

This repository ships design tokens, static assets, and UI components with no
server, no database, and no user data — the realistic risk surface is a
supply-chain issue in a dependency, a malicious contribution, or a leaked
credential accidentally committed here. Report any of those the same way you'd
report a vulnerability in a running product.

## Reporting a vulnerability

Email **security@blackpawinnovations.com**¹ with a description of the issue
and, if possible, steps to reproduce it. Do not open a public GitHub issue for
a security report on a repository this many products depend on.

You should receive an acknowledgement within 2 business days. We'll follow up
with an assessment and, if applicable, a timeline for a fix.

## Supported versions

Only the latest tagged release is supported. See `CHANGELOG.md` for the
current version and what's in it.
